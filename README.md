# A Magical Birthday Surprise Website for Mom (Amma) ❤️

A premium, world-class, responsive, and emotional birthday celebration website crafted with love for Amma.

## 🌟 Highlights

- **100% Zero Photographs or Stock Images**: Every floral bloom, glowing candle flame, butterfly, heart seal, and decorative element is created purely using CSS animations, SVG illustrations, golden foil gradients, and canvas sparkles.
- **Color Palette**: Luxury Pink (`#B76E79`, `#E0A9AF`), Rose Gold, Champagne Gold (`#D4AF37`, `#F7E7CE`), and warm glowing cream.
- **Typography**: Playfair Display, Cormorant Garamond, Great Vibes script, and Plus Jakarta Sans.

---

## 🌹 Website Structure

1. **Magical Introduction (`IntroEnvelope.jsx`)**:
   - Full-screen entrance with 3D animated envelope and glowing heart seal.
   - Interactive "OPEN YOUR SURPRISE ❤️" button with golden sparkles and sound chime.
2. **Hero Celebration (`HeroSection.jsx`)**:
   - "Happy Birthday, Amma!" with animated typography, layered CSS roses, floating butterflies, and scrolling indicator.
3. **A Letter From My Heart (`HeartLetter.jsx`)**:
   - Emotional open-letter parchment with typewriter reveal, ornate gold corners, and wax seal.
4. **Reasons Why You Are Special (`SpecialReasons.jsx`)**:
   - 6 luxury glassmorphism cards with custom SVG icons and glowing hover effects.
5. **Beautiful Birthday Wishes (`WishesSection.jsx`)**:
   - "May Your Dreams Bloom Like Flowers" with interactive blooming flower cards.
6. **Interactive Birthday Cake (`InteractiveCake.jsx`)**:
   - 3-tier CSS cake with realistic flickering candlelight.
   - "MAKE A WISH" button that blows out the flames, releases a smoke puff, and triggers a confetti & fireworks shower!
   - "LIGHT THE CANDLES AGAIN ✨" re-ignition option.
7. **Special Birthday Song (`MusicPlayer.jsx`)**:
   - Animated visualizer bars, spinning rose gold vinyl record, time progress scrubber, volume controls, and floating musical notes.
   - Works immediately out of the box with the included melody and supports your custom audio at `public/music/birthday-song.mp3`.
8. **Final Surprise (`FinalSurprise.jsx`)**:
   - Grand finale with golden particles, emotional dedication, and "CELEBRATE AGAIN 🎉" fireworks cannon.

## 🚀 Running the Project

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### Adding Your Own Birthday Song
Simply drop your desired MP3 file into:
```
public/music/birthday-song.mp3
```
The music player will automatically load and play your custom audio!
